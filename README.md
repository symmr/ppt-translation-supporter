# Translation Supporter

PowerPoint (`.pptx`)、Word (`.docx`)、PDF (`.pdf`) のテキストをブラウザ内で抽出し、翻訳文を書き戻すツール。ファイルはサーバへ送信されません。DOCX は本文、表、テキストボックス（`word/document.xml`）が対象です。ヘッダー、フッター、脚注は対象外です。PDF はテキストを持つページが対象で、スキャンした画像だけの PDF やパスワード付きの PDF は扱えません。

- **Web:** https://symmr.github.io/ppt-translation-supporter/
- **GitHub:** https://github.com/symmr/ppt-translation-supporter/

デッキ全体のフォント統一・画像圧縮・孤立メディア削除は [PPT Finalizer](https://symmr.github.io/ppt-finalizer/) で行います。

## 使い方

1. `.pptx`、`.docx`、`.pdf` のいずれかをドロップする（別のファイルを置くと、それまでの抽出テキスト・貼り付けた訳文・書き戻し結果はクリアされます）
2. 図の中の文字を載せる場合は、抽出欄の上にある「画像からテキスト抽出」を押す。本文に貼られた png / jpeg / webp だけが一覧になる。画像を選ぶとモーダルで読み取り結果が出る。不要な行は「消す」か「一括削除」で除く。原文は欄で直せる。「完了」でその画像のテキストボックスを載せ（同じ画像を再度開いて完了すると差し替え）、抽出テキストがやり直される。DOCX ではテキストボックスを図と同じグループに入れるので、図と一緒に動く
3. 抽出テキストと翻訳プロンプトをコピー、または `_to_translate.txt` をダウンロードする
4. 翻訳済みテキスト（`uid_0001` 行を残したもの）をドロップするか、画面に貼り付ける
5. `_translated.pptx` / `_translated.docx` / `_translated.pdf` をダウンロードする

翻訳そのものはこのページでは行いません。コピーしたプロンプトを LLM に渡し、返ってきたテキストをドロップまたは貼り付けてください。

翻訳の方向は「英語 → 日本語」（既定）と「日本語 → 英語」から選べます。選んだ方向はブラウザに保存されます。プロンプトは画面上で編集でき、編集内容は方向ごとにブラウザに保存されます。文体を変えたい場合は書き換えてください。「プロンプトを既定に戻す」で、いま選んでいる方向の既定値に戻せます。

書き戻すときにタイトルと本文のフォントを指定できます。候補は [PPT Finalizer](https://symmr.github.io/ppt-finalizer/) と同じおすすめフォントに加え、そのファイルが実際に使っているフォント（使用箇所数つき）と自由入力から選べます。既定は Noto Sans JP（翻訳の方向が「日本語 → 英語」のときは Arial）で、元のフォントをそのまま使う場合は「指定しない」を選びます。方向を切り替えると、既定のままのフォント指定だけが新しい方向の既定に変わり、自分で選んだフォントはそのまま残ります。指定した場合は訳文を書き戻した箇所にだけ適用されます。PPTX では `latin` / `ea` / `cs`、DOCX では `ascii` / `hAnsi` / `eastAsia` / `cs` を設定します。「タイトル」は、PPTX ではタイトルプレースホルダー（`title` / `ctrTitle` / `subTitle`）の図形、DOCX では見出しスタイル（`Title` / `Subtitle` / `Heading`）の段落が対象です。それ以外は本文フォントです。

タグ（`[0]...[/0]`）は run が2つ以上ある段落にだけ付きます。run が1つの段落の訳文にタグらしき文字列があっても、それは本文そのものとして扱い、加工せずに書き戻します（uid は警告に表示されます）。run が2つ以上ある段落で、タグが原文の run と1対1で対応しない場合は、先頭 run にまとめて書き戻します。文字は入りますが run ごとの書式（色分けなど）は失われるため、該当件数と uid が警告に表示されます。

## PDF

PDF は、同じ行で続く文字を1行にまとめ、行間と文字サイズが揃った連続行を1ブロック（段落）として抽出します。表のセルのように横に離れた文字は別ブロックです。ただし文字1つ分より狭い間隔で並んだセルは、pdf.js が1つの文字列にまとめるため1ブロックになります。横書き以外の文字は対象外です。

文の途中で文字色やリンクが変わるブロックには、PPTX と同じタグ（`[0]...[/0]`）が付きます。色はページの描画命令から、リンクはリンク注釈から読み取ります。太字（フォント名に Bold / Medium などを含むもの）もタグの区切りになり、書き戻しでは Noto Sans JP Bold を使います（太字がある PDF だけ、太字フォントも読み込みます）。斜体は区別しません。同じ大きさでも、行末と次の行頭でフォントが変わる場合（太字の見出しと本文など）は別ブロックにします。箇条書きの記号や番号（•、❏、1.、a. など）で始まる行は新しいブロックにし、記号や番号だけのブロック（文字を含まないもの）は抽出しません。PDF 上もそのまま残ります。完全に透明な文字（PowerPoint の画像の代替テキストなど）も抽出しません。タグが原文と1対1で対応しない訳文は、いちばん長い run の色でまとめて書き、uid を警告に表示します。「画像からテキスト抽出」は PDF では使えません。

書き戻しの出力形式は次の2つから選べます。

- **PDF（原文を訳文に書き換える）**: ページの描画命令（コンテンツストリーム）から各ブロックの原文を取り除き、同じ位置に訳文を Noto Sans JP（サブセット埋め込み）で書き込みます。背景・図形・画像には手を付けないので、色付きの帯や表の罫線はそのまま残り、出力 PDF の検索やコピーでは訳文だけが拾われます。消した文字の幅ぶんだけ文字送りを残すので、同じ行の訳さない文字は位置がずれません。訳文はタグごとに元の文字色で書きます。埋め込みフォントにない記号（❏ や Wingdings の箇条書き記号など）は、□ や • などの似た記号で書きます。リンクはクリック範囲を訳文の該当部分に移し、リンクのすぐ下にある細い線（下線）は消して訳文の下に引き直します。1行のブロック（見出し・ラベル）は、右隣のテキストや背景色の切れ目（色付きの箱の端など）に当たるまで、元の幅の 1.8 倍まで広げてから小さくします。枠に収まらない訳文は元の 50% まで小さくし、それでも収まらなければページ右端まで幅を広げます。それでもはみ出した uid は警告に表示されます。ヘッダーやフッターによく使われるフォーム XObject の中の文字も消します（複数ページで共有されているものは1回だけ書き換えます）。スキャン PDF の透明な OCR テキストは消しますが、見えている文字は画像の一部なので、そのブロックだけ背景色の矩形で覆って訳文を書き、uid を警告に表示します。フォント指定は使いません。
- **Word（.docx）**: ページ順に、1ブロック1段落で訳文を並べた文書を作ります。タグごとの文字色と、URL のリンク（ハイパーリンク）を引き継ぎます。ページの区切りで改ページし、元の文字サイズを引き継ぎます。本文より明らかに大きいブロックは太字の見出し（タイトルフォント）にします。図・表・配置は引き継ぎません。訳文がない uid は原文のまま入ります。

PDF 関連のライブラリ（pdf.js、pdf-lib、fontkit）とフォント（約 5MB）は、PDF を置いたとき・PDF を書き出すときに CDN から読み込みます。

## サンプル

手動確認用の小さなデッキは `test/fixtures/smoke-test.pptx`。2 枚。見出し、色の違う run（`[0]...[/0]`）、表、スピーカーノート、製品名混在。再生成:

```sh
python test/fixtures/build_smoke_pptx.py
```

## PDF のサンプル

手動確認用の PDF は `test/fixtures/pdf-styled-sample.pdf`。文中の色違い、下線付きリンク（https / mailto）、文字入りの画像、写真の上の白文字を含む。再生成（Playwright と Chromium が必要）:

```sh
node test/fixtures/build_pdf_sample.cjs
```

## 開発

```sh
npm install
npm test
```

リポジトリ構成: `docs/index.html`（UI）+ `docs/app.js` + `docs/pptx-text.js`（PPTX の抽出・書き戻し）+ `docs/docx-text.js`（DOCX の抽出・書き戻し）+ `docs/pdf-text.js`（PDF の抽出・書き換え・Word 出力）+ `docs/pdf-rewrite.js`（PDF コンテンツストリームから原文を取り除く）+ `docs/version.json`。
