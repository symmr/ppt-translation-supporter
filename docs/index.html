PPT Translation Supporter

ブラウザ内で PowerPoint のテキストを抽出し、翻訳文を書き戻します。翻訳自体はこのツールでは行いません。抽出したプロンプトと本文を ChatGPT や Claude などの LLM に渡し、返ってきた訳文をこのツールで書き戻してください。ファイルはサーバに送られません。デッキ全体のフォント統一は PPT Finalizer で行います。

1

PPTX を置く

ここに .pptx をドロップ

またはクリックして選択

2

テキスト抽出とプロンプト

下のプロンプトと本文をコピーし、ChatGPT や Claude などの LLM に貼り付けて翻訳してください。返ってきた訳文は次のステップで貼り戻します。

3

翻訳したテキストを渡す

書き戻すときにフォントを指定できます。空欄なら元の PPTX のフォントを変更しません。指定した場合、訳文を書き戻した箇所にだけ適用されます（デッキ全体の統一は PPT Finalizer で行います）。「タイトル」はタイトルプレースホルダーの図形が対象です。テキストボックスだけで作られたスライドにはタイトルの区別がないため、すべて本文として扱われます。

ここに翻訳済み .txt をドロップ

またはクリックして選択

4

翻訳済み PPTX をダウンロード
