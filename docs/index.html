PPT Translation Supporter

ブラウザ内で PowerPoint のテキストを抽出し、翻訳文を書き戻します。翻訳自体はこのツールでは行いません。抽出したプロンプトと本文を ChatGPT や Claude などの LLM に渡し、返ってきた訳文をこのツールで書き戻してください。ファイルはサーバに送られません。デッキ全体のフォント統一は PPT Finalizer で行います。

1

PPTX を置く

ここに .pptx をドロップ

またはクリックして選択

2

テキスト抽出とプロンプト

画像を選択してください。自動抽出開始を押すとテキストを読み、テキストボックスとして被せます

画像上をドラッグすると、囲んだ範囲だけを1件として読みます。

確認終わればページ下部の完了ボタンをクリックしてください

多め 確実なところだけ

    下のプロンプトと本文をコピーし、ChatGPT や Claude などの LLM に貼り付けて翻訳してください。返ってきた訳文は次のステップで貼り戻します。

    3

    翻訳したテキストを渡す

    書き戻すときにフォントを指定できます。既定は Noto Sans JP です。元の PPTX のフォントをそのまま使う場合は「指定しない」を選んでください。指定したフォントは訳文を書き戻した箇所にだけ適用されます（デッキ全体の統一は PPT Finalizer で行います）。「タイトル」はタイトルプレースホルダー（title / ctrTitle / subTitle）の図形が対象です。テキストボックスだけで作られたスライドにはタイトルの区別がないため、すべて本文として扱われます。

    またはクリックして選択

    4

    翻訳済み PPTX をダウンロード
